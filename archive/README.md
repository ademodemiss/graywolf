# Archive

Bu klasör runtime dışı, tek-seferlik veya tarihi referans dosyalarını tutar.

## root_legacy/
Kök dizinde dağınık duran yardımcı script, eski rapor çıktısı ve tek kullanımlık doğrulama dosyaları buraya taşındı.

Kural:
- Runtime kodu (`core/`, `tools/`, `monitor/`, `dashboard/`, `adapters/`) buraya taşınmaz.
- Arşiv dosyaları gerekiyorsa tekrar köke alınabilir; varsayılan olarak ürün akışında kullanılmaz.
